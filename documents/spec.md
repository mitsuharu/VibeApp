# 海外旅行のプランを半自動で作ってくれる

## 仕様書

「海外旅行のプランを半自動で作ってくれる」モバイルアプリの仕様書です。

### 機能概要

シンプルで使いやすい海外旅行プラン作成アプリ

1. **国選択**: 世界12カ国から旅行先を選択
2. **目的選択**: 6つの旅行目的から選択  
3. **AIプラン生成**: useAssistant を使って時間単位の詳細な旅行プランを自動作成
4. **結果表示**: 時間単位スケジュールを含む旅行プランを美しく表示

### 詳細仕様

#### 1. 国選択画面
**対応国（12カ国）**:
- **ヨーロッパ**: 🇫🇷 フランス、🇮🇹 イタリア、🇪🇸 スペイン、🇬🇧 イギリス、🇩🇪 ドイツ
- **北アメリカ**: 🇺🇸 アメリカ、🇨🇦 カナダ
- **アジア**: 🇰🇷 韓国、🇹🇭 タイ、🇸🇬 シンガポール
- **その他**: 🇦🇺 オーストラリア、🇦🇪 UAE

地域別に分類し、国旗と名前で表示

#### 2. 目的選択画面
**旅行目的（6種類）**:
- 🏛️ **観光**（名所・観光地巡り）
- 🍽️ **グルメ**（現地料理・レストラン体験）
- 🛍️ **ショッピング**（お買い物・お土産探し）
- 🎨 **文化体験**（美術館・博物館・文化体験）
- 🧘‍♀️ **リラックス**（スパ・リゾート・癒し）
- 🏃‍♂️ **アクティビティ**（スポーツ・アウトドア活動）

絵文字と説明文で視覚的に分かりやすく表示

#### 3. AIプラン生成
**useAssistant を使用した詳細プラン作成**:
- 選択した国と目的に基づいてプロンプト生成
- OpenAI GPT-4 API を使用
- 3泊4日の時間単位詳細スケジュール
- 実用的で具体的な旅行情報を生成

#### 4. 結果表示画面
**時間単位の詳細スケジュール**:
- **1日目（到着日）**: 08:00〜 出発から現地到着まで時間単位
- **2日目（観光メイン）**: 07:00〜20:30 観光スポット巡り時間割
- **3日目（テーマ別）**: 選択目的に特化した1日の時間割
- **4日目（帰国日）**: チェックアウトから出発まで

**追加情報**:
- 移動手段と所要時間
- グルメ・レストラン情報（営業時間含む）
- 宿泊先提案（エリア・特徴・予約コツ）
- 詳細予算（項目別）
- 注意事項・持ち物・アドバイス

**機能**:
- 別プラン生成（異なるアプローチで再生成）
- 最初から始める（国選択に戻る）

## 技術仕様

### 基本構成
- **フレームワーク**: React Native + Expo
- **ルーティング**: Expo Router (file-based routing)
- **対応プラットフォーム**: iOS、Android、タブレット対応
- **モバイルファースト**: スマートフォンでの操作性を最優先

### UI/UX設計
- **コンポーネント**: @mitsuharu/react-native-components-plus を使用
- **スタイリング**: react-native-swag-styles
- **カラーシステム**: src/constants/Colors.ts の統一カラー
- **レスポンシブ**: タブレット・スマートフォン両対応
- **タッチ操作**: 大きなタップエリア、指に優しいUI

### ディレクトリ構造
```
src/
├── app/                    # Expo Router画面
│   ├── index.tsx          # スプラッシュ画面
│   ├── country-selection.tsx    # 国選択画面
│   ├── purpose-selection.tsx    # 目的選択画面
│   └── travel-plan-result.tsx   # 結果表示画面
├── components/            # 共通コンポーネント
├── constants/            
│   └── Colors.ts         # カラーシステム
├── hooks/
│   └── useAssistant.ts   # OpenAI API連携
├── types/
│   └── index.ts          # 型定義・データ
└── utils/                # ユーティリティ
```

### AI統合
- **API**: OpenAI GPT-4
- **Hook**: src/hooks/useAssistant.ts 使用
- **プロンプト**: 時間単位詳細スケジュール生成用に最適化
- **エラーハンドリング**: オフライン・API障害対応

### モバイル最適化
- **キーボード対応**: KeyboardAvoidingView 使用（不要な場合は削除済み）
- **スクロール**: 縦スクロール中心の設計
- **タッチ**: 44px以上のタップターゲット
- **パフォーマンス**: 軽量化・高速レンダリング
- **アクセシビリティ**: VoiceOver・TalkBack対応

### データ仕様
- **国データ**: 12カ国ハードコード（国旗絵文字付き）
- **目的データ**: 6種類ハードコード（アイコン絵文字付き）
- **認証**: 不要（シンプル化）
- **ローカルストレージ**: 最小限の状態管理
